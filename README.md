# Page_object_pattern
Четвёртый модуль курса ["Автоматизация тестирования с помощью Selenium и Python"](https://stepik.org/course/575/) на stepik

---
## Запуск
Возможны две настройки:
+ Язык (поддерживаются любые языки, которые сможет обработать сайт :D ): --language
+ Браузер (chrome или firefox): --browser_name

По умолчанию стоят _en_ и _firefox_. На _chrome_ тесты могут быть стабильнее. Так же, могут быть проблемы непосредственно с доступом к сайту.

---

## Описание страниц
1. BasePage
   + Основа каждой из страниц, содержит в себе общие методы. Инициализация каждой страницы происходит с переданным адресом, либо с дефолтным.
Использованы явные ожидания для методов.
2. MainPage
    + Главная страница. В итоговом варианте проекта не используется почти никак, поэтому содержит в себе лишь дефолтную ссылку.
3. LoginPage
    + Страница регистрации и входа в аккаунт. Имеет дефолтную ссылку, умеет проверять корректность перехода на форму, регистрировать пользователя.
4. ProductPage
    + Страница продукта. Имеет дефолтную ссылку, умеет добавлять продукт в корзину, проверять успешность добавления.
5. BasketPage
    + Страница корзины. Имеет дефолтную ссылку, умеет проверять пустоту корзины.
---
## Описание тестов
1. test_main_page
    + Проверки на возможность открыть страницу регистрации и входа в аккаунт с главной страницы.
    + Проверка на пустоту корзины в начале работы с сайтом. 
2. test_product_page
    + Проверка промо-страниц на корректное добавление товара в корзину.
    + Тесты на проверку работы сообщения об успехе добавления товара в корзину.
    + Проверка возможности незарегистрированному пользователю перейти на страницу логина, а так же имеет чистую корзину.
    + Проверка возможности зарегистрированным пользователем добавить продукты в корзину.
